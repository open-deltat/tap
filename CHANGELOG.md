## [0.1.0] - 2025-01-XX

### Added
- Initial release of TAP (Time Allocation Protocol)
- `@tap/protocol` - Zod schemas, types, and constants
- `@tap/core` - Business logic and availability calculation
- `@tap/client` - Browser/Node.js SDK
- HTTP API for availability, booking, and offers
- WebSocket API for real-time holds and availability streaming
- Database-backed API key authentication
- Federation discovery endpoint
